# Tron Mod

A Tron-inspired Minecraft mod built with NeoForge.

## Development

- Minecraft: 26.1
- NeoForge: 26.1.2.94
- Java: 25

Build the mod on Windows:

```powershell
.\gradlew.bat build
```

Run a development client:

```powershell
.\gradlew.bat runClient
```

The built JAR is written to `build/libs/`.
